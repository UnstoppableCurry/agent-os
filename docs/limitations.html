局限与证据边界

项目处于早期。下面只列能在文件里指出的缺口，不补充「即将上线」或「已有用户」之类无法核验的句子。

源码标明或可观察的未完成

  • backend/src/skill/mod.rs：仅注释「future expansion」。
  • backend/src/sensor/mod.rs：同样是未来扩展桩。
  • 后端目录没有 #[cfg(test)]；make test-backend 不会覆盖业务逻辑。
  • LifeKit 有模型、缓冲与隐私的单元测试；没有看到对真实服务器的集成测试。
  • DashboardView 未接入主导航，refreshData() 为空，统计与活动是示例常量。
  • Health / Calendar / Contacts Sensor 类型存在，设置页有开关，不能据此声称采集链路已跑通。
  • 镜像层目前主要是模板，未见后端定时生成周报/月报/年报的实现。
  • 晶体「从流中提炼」在文档中是目标；CrystalStore 只做文件读写，没有提炼任务。

文档与实现漂移

  • API 前缀：文档 /api/... 与 /ws；代码 /v1/... 与 /v1/bots/{id}/ws。
  • 记忆检索 GET /api/memory/query、技能列表 GET /api/skills：路由表中不存在。
  • SQLite、AGENT_OS_PORT、ANTHROPIC_API_KEY：文档有，后端 crate 未兑现。
  • LifeKit query 的路径与后端晶体路由不一致。
  • 模块树：CLAUDE.md 未更新到 bot/ 与 engine/。

本站拒绝发明的内容

  • 界面截图：仓库没有 App 或后端的屏幕图像，故不用示意图冒充产品 UI。
  • 平台已验证：不写「已在 iPhone / iPad / Mac 全系可用」。只引用 Package.swift 与 project.yml。
  • 用户、案例、效果：没有任何评测、星标或引用可引用，故不写。
  • 24 小时自动化已实现：这是 README 目标句，不是运行报告。空闲管理与进程监督存在，不等于全天候可靠性。
  • 个人记忆正文：不复制 SOUL.md 或晶体中的身份信息。

这个静态站本身

  • 只发布 docs/，避免把 data/ 会话或记忆原文打进 Pages 产物。
  • 无第三方脚本与字体；样式为自托管 CSS。
  • 启用仓库的 GitHub Pages 时，需要在仓库设置里把来源选成 GitHub Actions。工作流本身不会改这项设置。
