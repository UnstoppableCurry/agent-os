项目卡

是什么

个人向的 Agent 编排与记忆实验：Rust 后端管进程与事件，SwiftUI 客户端做聊天与设置，LifeKit 作为把 App 事件送进记忆系统的 SDK。

仓库声明的技术栈

后端 Rust / Axum / Tokio；客户端 SwiftUI / Combine；SDK 为 Swift Package；通信 WebSocket + JSON；AI 接口在 README 中写为 Claude API（Anthropic）。后端 Cargo.toml 版本号为 0.1.0。

源码里实际能看到的

Bot 的创建、列表、SSE 发消息、按 Bot 的 WebSocket、事件写入按日 JSONL、晶体 Markdown 读写。引擎适配器通过本地 CLI 进程对接 Claude Code、Kimi、Codex。

明确未宣称

本站不展示伪造界面、不声称已上架商店、不给出下载量或满意度。平台范围以清单文件为准，见结构与局限页。

愿景（来自 README 与 CLAUDE.md）

  • 每个 App 是触角：收集数据、执行任务。
  • 记忆系统是灵魂：事件汇入统一记忆流。
  • Agent 是大脑：从记忆学习、决策、行动。

记忆哲学在文档中分成四层：流（只增时间线）、晶体（从流提炼的结构化知识）、镜像（定期复盘）、根基（memory/bedrock/SOUL.md 等手写灵魂定义）。晶体「定期提炼」与镜像「自动生成」在源码中尚未形成完整流水线，见局限页。

仓库记载的本地命令

README 与根目录 Makefile 提供后端构建/运行，以及 LifeKit 构建与测试。没有独立的 App 构建目标。

# 构建后端
make build-backend

# 运行后端
make run-backend

# 构建 LifeKit SDK
make build-lifekit

# 运行测试（后端 cargo test + LifeKit swift test）
make test

后端入口将监听地址写死为 0.0.0.0:3000。健康检查返回 version: 0.1.0。
